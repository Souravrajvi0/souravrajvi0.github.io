IPO Tracker — Backend system tracking IPO subscription data and Grey Market Premium (GMP) in near real-time. Scheduled ingestion pipeline (every 30 min), time-series snapshots to analyze demand momentum, trend-based logic to detect accelerating vs cooling demand, and APIs exposing current state, history, and a final recommendation. Built with Puppeteer, PostgreSQL, and Node.js/React.

IPO Tracker

LSM Tree Storage Engine — Custom LSM Tree storage engine implementing MemTable, SSTables, and Bloom filters, achieving 3,500+ writes/sec with 97% test coverage. Explores the concepts behind systems like RocksDB and Cassandra. Includes a live visualizer for the write path and compaction process.

LSM Tree Engine

OpenInference CLI — Hardware-aware package manager for local AI models. Profiles CPU, RAM, GPU, disk, and OS, then recommends models from a 150+ model catalog that will realistically run on the machine. Guided setup wizard, unattended mode for CI/cloud VMs with automatic fallback to smaller models, and Ollama as the inference backend. TypeScript/Node.js, distributed via npm, ~11,100 downloads/month, MIT licensed.
